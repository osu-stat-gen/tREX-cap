# tRexCAP

tRex-CAP (Cut and Paste) uses the tREX algorithm as the building block
and a divide and conquer strategy to reconstruct whole genome
three-dimensional structures from Hi-C Data.

# Installation

You can install tRex-CAP package directly from github by using your
favorite installer (remotes/devtools/pak):

``` r
remotes::install_github("osu-stat-gen/tREX-cap",  build_vignettes = TRUE)
```

Note: For OSX, make sure you have gsl and openMP installed before
installing tRex-CAP.

# Vignette

The vignette can be accessed

``` r
vignette(tRexCAP)
```

It is also available as a webpage in the `vignette` directory of this
repository.
